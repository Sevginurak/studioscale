# Working notes

## Delivery preferences
- Always deliver each Behance section and each Dribbble shot as its own image file at full export resolution (2x), sent individually in publishing order.
- Never send a stitched or downscaled overview in place of the section files. An overview is fine only as an extra.

## Design rules (apply on every project)
- Never crop content along an invisible frame edge (e.g. a hidden clipping viewport that cuts a device in a straight line). Content may only be cut by a visible panel/card edge or the section's own outer edge; otherwise keep it fully in view.
- No gradient fades that wash over screens or UI (e.g. brand colour → transparent overlays on top of screenshots). Use crisp edges, panels or clipping instead.
- Show only the most important, distinctive features. Don't present every screen or secondary functions (e.g. "Move to", folder menus). Curate; you don't have to show everything in the Figma file.
- UI Design grids: a curated selection of key screens, not every screen.
- Empty-state sections: show the empty-state illustrations, not whole screens.
- Check icons carefully at high zoom before delivering (swapped icon instances must render at their own component size).
